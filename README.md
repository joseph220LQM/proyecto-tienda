# Proyecto Tienda — Java Swing + MySQL

Aplicación de escritorio para la gestión de clientes, productos y ventas de artículos masculinos y femeninos.

## Tecnologías
- Java + Swing (interfaz gráfica)
- MySQL (base de datos)
- JDBC conector 9.6 / 9.7

## Módulos
- **Clientes:** registrar, consultar, modificar y eliminar.
- **Productos:** registrar, consultar, modificar y eliminar; clasificación masculino/femenino.
- **Ventas:** registrar, consultar y controlar; asociar productos y clientes.
